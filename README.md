# Omnichannel Retail Analytics Data Platform

## Project Overview

This project simulates an omnichannel retail analytics platform.

The goal is to transform raw retail data into trusted analytics assets using:

- Python
- SQL
- Snowflake
- Power BI

## Business Scenario

Data sources:

- E-commerce transactions
- Store sales
- Inventory systems
- Customer data
- Marketing campaigns

## Tools

- Python
- SQL
- GitHub
- Snowflake
- Power BI
